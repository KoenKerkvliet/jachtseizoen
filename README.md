# Jachtseizoen

Een mobiele webapp voor een besloten Jachtseizoen-spel: maak een sessie, deel een code en speel met boeven, vangers en een spelleider.

## Eerste versie

- Een sessie starten of met een code deelnemen
- Rollen kiezen
- Afteltimer en missie-overzicht
- Foto-hints als volgende uitbreiding
- Later: Supabase voor realtime spelers, locaties en foto-opslag

Deze eerste versie is bewust een statische webapp. Daardoor is hij meteen via GitHub Pages te bekijken en kunnen we daarna gericht de realtime functies toevoegen.
